# EPI590R repo

This repository belongs to Leah Sang, and containts data from the IELTS research website and contains mean scores in various aggregations. 
The dataset was curated by Elio Campitelli, which was uploaded to the tidytuesday repository created by the Data Science Learning Community on github. 

Run script.R and then render document.qmd

Note on AI usage during this project:
For the creation of my function "type_score_avg", I used Google's AI overview to fix my code to allow the data to be filtered by test type to create the overall averages for each. 
The code for my function is tailored based on the following search prompt: "Can I get an example of how to put a filter for a variable with categorical data in a function that I am creating in rstudio". I modified the code myself based on my dataset and the information I wanted.
